# POF 发布与更新

## 文件上传位置

| 内容 | 上传位置 | 什么时候需要更新 |
| --- | --- | --- |
| Windows 安装包 | `Baozi-Pei/POF-Releases` → Releases → 发布版本的附件 | 每次发布软件新版本 |
| 便携 ZIP | 同一 Release 的附件 | 需要提供便携版时 |
| 网页、使用手册和截图 | 本仓库 `main` 分支 | 修改网页或手册时 |

仓库地址：https://github.com/Baozi-Pei/POF-Releases

## 首次上线

1. 将网站文件推送到仓库 `main`。
2. 打开仓库 **Settings → Pages**，把发布来源设为 **GitHub Actions**。
3. 在 **Actions → Publish POF website** 中确认部署成功。
4. 访问 `https://Baozi-Pei.github.io/POF-Releases/`，检查首页和使用手册。
5. 按下述步骤发布第一个软件版本，再验证实际下载。

上述是首次配置步骤。后续网页提交到 `main` 后会自动部署。

## 发布软件新版本

1. 先更新软件内部版本号并重新打包。例如当前 `0.2.0`，下一版可以使用 `0.2.1`。
2. 打开仓库 **Releases → Draft a new release**。
3. 创建对应版本标签，例如 `v0.2.1`；使用标准的三段版本号。
4. 填写版本标题和本次更新说明。
5. 上传安装包，文件名必须保持为 **`POF-Workbench-Setup.exe`**。
6. 如需便携版，再上传 **`POF-Workbench-Portable.zip`**。
7. 等附件完整上传后，发布为正式版本。需要面向普通用户时，不要标为预发布；确认 GitHub 将其设为 Latest。
8. 打开网站确认显示新版本，并实际下载一次。检查安装包大小和 SHA-256 与本地发布文件一致。
9. 使用旧版本软件检查更新，确认能发现新版本并完成后台下载。自动安装会等待软件正常退出，不应打断正在运行的工作。

软件自动更新使用 GitHub 返回的附件大小和 SHA-256。没有完整安装包、版本号不符合要求、版本不更新或校验信息尚未就绪时，更新不会被直接安装。

## 更新网页或手册

网页内容提交到 `main`，GitHub Actions 会重新部署。手册在线版位于 `manual/index.html`，截图位于 `manual/manual-images/`，下载版位于 `manual/POF-Workbench-Manual.zip`。修改手册时应同步更新在线版、截图和下载版。

只发布软件新版本时，网站会自动读取最新 Release，不需要为下载按钮逐次修改链接。
